# Deep.Protocol.ProfileCarrier

Unsigned exact `DPF1` carrier composition and verification over the pinned
`Deep.Protocol/P04-canonical-v1` trust authority.

This package has no signer, private-key, persistence, network,
dependency-injection, runtime or activation API. Production verification and
activation remain blocked pending separate cryptographic and client reviews.

The complete contract and offline reproduction instructions are maintained in
`docs/deep-extension-profile-carrier-v1.md` in the source repository.
