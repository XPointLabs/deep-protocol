# Deep.Protocol.ProfileCarrier

Dormant exact `DPF1` carrier composition, transition re-verification,
capability-specific post-consent UserManaged activation contracts and
verify-only Ed25519 candidates over the pinned
`Deep.Protocol/P04-canonical-v1` trust authority.

This package has no signer, secret-key custody, persistence, network,
dependency-injection or enabled runtime. The activation seam requires exact
DPF re-verification, local single-use consent/LKG enforcement and a canonical
online-quorum-signed SHR1 runtime envelope; protected persistence, acquisition,
TLS/SPKI enforcement, external cryptographic review and client activation
remain separate blocked work.

The complete contract and offline reproduction instructions are maintained in
`docs/deep-extension-profile-carrier-v1.md` in the source repository.
